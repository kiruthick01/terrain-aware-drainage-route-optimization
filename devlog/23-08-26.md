# 2026-08-23

2b.4 - manual RAS Mapper model build. GUI work, tracked here since
hecras/ is entirely gitignored (binary/GUI-built, per the .gitignore
rule added 2026-08-22) - this devlog is the only record of GUI-side
progress.

## Done so far

- New HEC-RAS project created: "Velachery MVP Flood model" at
  hecras/velachery_mvp/velachery_mvp.prj
- Projection set to EPSG:32644 (UTM 44N). Pulled the exact WKT off
  dem_reprojected.tif via rasterio and saved it as
  hecras/velachery_mvp/epsg_32644.prj so RAS Mapper could load it
  directly instead of hand-typing/searching spatialreference.org
- Imported dem_reprojected.tif as the project Terrain (Terrain.hdf).
  Cell size confirmed 30.34m on import - matches the DEM, so the
  translate/rounding step didn't distort anything
- Switched project unit system to SI. Tripped us up for a bit - the
  toggle is NOT in RAS Mapper Options (that only has display/decimal
  settings), it's in the main HEC-RAS window's Options menu ->
  "Unit System (US Customary/SI)". Confirmed applied: RAS Mapper's
  scale bar went from "2000 ft" to "2 km" after switching
- Created a new Geometry ("New Geometry"), auto-associated with the
  Terrain
- Converted data/raw/zone_boundary.geojson (5-vertex rectangle,
  EPSG:4326) to EPSG:32644 and saved as
  hecras/velachery_mvp/gis_import/zone_boundary_utm44n.shp, so it's
  in the same CRS/units as everything else in the project
- Drag-dropped that shapefile onto the RAS Mapper canvas while in
  "Editing: 2D Flow Areas" mode. It imported as a **reference Map
  Layer** (visible black outline on the terrain), not as the actual
  2D Flow Area boundary - useful as a visual guide for manual
  tracing, but doesn't create the flow area geometry by itself

## Where to pick back up

1. In RAS Mapper, re-enter 2D Flow Area edit mode (click the pencil
   icon next to "2D Flow Areas" in the Geometries tree if not
   already active)
2. Hover (don't click) every icon in that edit toolbar left to
   right, note the tooltip names, find the polygon/area draw tool
3. Use it to trace a boundary over the black zone_boundary_utm44n
   reference rectangle already on the canvas - doesn't need to be
   pixel-precise, a few meters off the reference is fine at 10m
   mesh resolution
4. Set 2D Flow Area mesh cell size to 10m x 10m, generate the mesh
5. Attach Land Cover (data/processed/landuse.tif +
   landuse_classes.csv for Manning's n) and Curve Number
   (data/processed/curve_number.tif, normal/AMC-II first) layers
6. Set up the precipitation (rain-on-grid) boundary condition and
   build the unsteady plan template (storm duration + drain-down
   tail, time step sized to Courant condition at 10m)
7. That closes out 2b.4 - 2b.5 (hecras_adapter.py automation) is
   next after that, per ROADMAP.md
